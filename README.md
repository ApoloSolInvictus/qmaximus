# Quantum Maximus

Sitio web estatico local sobre el nombre Maximus, la palabra quantum, computacion cuantica y el arquetipo creativo Quantum Maximus / Quantumus.

## Abrir localmente

Abre `index.html` en el navegador. No requiere servidor ni dependencias.

## Herramienta incluida

El sitio trae un traductor binario bidireccional:

- Texto humano a binario UTF-8.
- Binario separado por espacios a texto humano.
- Soporta acentos y simbolos gracias a `TextEncoder` y `TextDecoder`.

## Nota de Veritas

Maximus y quantum tienen base linguistica/historica verificable. Quantum Maximus y Quantumus se presentan como mitologia creativa moderna, no como entidades historicas comprobadas.
